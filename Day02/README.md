
# 📅 Day 02 – JavaScript Data Types

## 1. What are Data Types?

Data types specify what kind of value a variable can store.

## 2. Types of Data Types

JavaScript data types are divided into two categories:

### A. Primitive Data Types

1. String – Stores text.
2. Number – Stores integer and decimal numbers.
3. Boolean – Stores true or false.
4. Undefined – Variable declared but not assigned a value.
5. Null – Represents intentional absence of a value.
6. BigInt – Stores very large integers.
7. Symbol – Creates unique identifiers.

### B. Non-Primitive Data Types

1. Object – Stores data in key-value pairs.
2. Array – Stores multiple values in one variable.
3. Function – Reusable block of code.

## 3. typeof Operator

The `typeof` operator is used to identify the data type of a value.

Example:

```javascript
let name = "Krishnaveni";
let age = 25;
let isStudent = true;

console.log(typeof name);
console.log(typeof age);
console.log(typeof isStudent);
```

Output:

```text
string
number
boolean
```

## 4. Important Points

- JavaScript has seven primitive data types.
- Arrays are non-primitive objects.
- Objects store data in key-value pairs.
- `typeof null` returns `"object"` because of historical JavaScript behavior.
- `Array.isArray()` checks whether a value is an array.
- JavaScript is a dynamically typed language.
